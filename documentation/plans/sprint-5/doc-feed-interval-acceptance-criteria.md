# DOC-FEED-INTERVAL - per-feed schedule for AutoCount Document feeds - acceptance criteria

Lane DOC-FEED-INTERVAL. Status: **Plan** (behaviour card under owner review on the PR).

Goal: the owner sets how often each Document feed (Delivery orders, Goods receive
notes) runs, using the same mechanism as the Entities tab schedule. Defaults keep
today's behaviour (poll 60 min, sweep 24 h) until edited.

ACs are filled in once the behaviour card is answered.
