B. One scheduled job that collects leads

Every minute your backend asks for new leads and creates them.

GET https://ss.example/be/api/v1/lead-capture/leads?cursor=<saved cursor> Authorization: Bearer fxl_live_...

First run: ?since=2026-11-18T00:00:00Z instead of cursor. The answer (fake data):

{ "data": [{ "id": "e3a10000-0000-0000-0000-000000000001", "sourceId": "4c1f0000-0000-0000-0000-000000000001", "formName": "Year-end promo", "receivedAt": "2026-11-18T03:20:05Z", "createdAt": "2026-11-18T03:20:00Z", "isTest": false, "fields": {"name": "Test Person", "phone": "+60120000000", "email": "test.person@example.com", "notes": "property_type: Condominium\nbudget: RM 500k - 800k"}, "answers": [...], "attribution": {...} }], "nextCursor": "WyIyMDI2LTExLTE4VDAzOjIwOjA1...", "hasMore": false }

The job, in four steps

  1. For each item create a lead (status New, source Facebook): name → Client name, phone → Phone, email → Email, notes → Remarks.
  2. Save id on the lead with a unique constraint; if it already exists skip the item, so a re-run never creates a duplicate.
  3. Save nextCursor and use it on the next run. (An empty first since page has nextCursor: null: call with the same since again.)
  4. If hasMore is true, call again straight away.

isTest: true = Meta's dummy test lead; show or skip it. A lead shows in the pull about 5 seconds after it is stored.

Faster delivery and your own field names

Instant push instead of every minute

The Shared Service posts each lead to one backend URL the moment it arrives (same lead shape, same id), signed with X-Lead-Capture-Signature: t=...,v1=.... Verify it:

import hashlib, hmac, time def verify(secret, header, raw_body): parts = dict(p.split("=", 1) for p in header.split(",") if "=" in p) t, v1 = parts.get("t", ""), parts.get("v1", "") if not t.isdigit() or abs(time.time() - int(t)) > 300: return False expected = hmac.new(secret.encode(), t.encode() + b"." + raw_body, hashlib.sha256).hexdigest() return hmac.compare_digest(expected, v1)

Register the URL with POST /be/api/v1/lead-capture/webhooks. Answer any 2xx once the lead is saved; retries run 1 min, 5 min, 30 min, 2 h, 6 h, 24 h.

Your own field names

PUT https://ss.example/be/api/v1/lead-capture/fields [{"key": "property_type", "label": "Property type", "type": "text"}, {"key": "budget_range", "label": "Budget range", "type": "text"}, {"key": "remarks", "label": "Remarks", "type": "notes"}]

The Fields step then maps form questions onto these instead of Remarks. Types: name, phone, email, notes, text; at most 50.
