What changes

  • One new row, "Outbound messages", in the existing Events picker. The NEW tag and tint are for this mock only and do not ship.
  • No layout change, no new component, no new screen. The picker now has 5 rows instead of 4.
  • The same picker appears in Add endpoint and Edit endpoint.

Why it cannot stay API only

  • An endpoint created through the API can subscribe to this event. The picker hides values it does not list (multi-select.tsx:74), and "Select all" replaces the whole selection (multi-select.tsx:148), so an admin editing that endpoint could silently drop the event.
