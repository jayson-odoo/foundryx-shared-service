Left out on purpose

  • No hint or description under the switch. The label is the whole control.
  • No prerequisite warning: the workflow engine is part of the platform and always on, and this tab only exists inside an enabled omnichannel module, so nothing can be missing.
  • The switch is not rendered for a user who lacks the workflow permissions it grants. That user sees today's dialog.
  • No dropdown in this dialog, so no SearchSelect.
