Claude connector admin - mockup v1

Lane SS-CONNECTOR-L, PR #117. The SS-side admin surface only: the consent screen is sorento's own page (crew Q1 b), so SS shows no consent UI. Case: the sorento product connection, its real tool names from sorento's manifest (app/services/analytics_connector/manifest.py, reused_tools.py) and real sorento role names from dev data (user_roles on sorento_acm_dev). Person names and emails are replaced by the user's role in brackets because sorento-crm is a public repo and this mock must carry no person data; the live page shows the name from the grant's snapshot.
