### Tenant Branding / White-label (LIVE since sprint-2/03)
Per-tenant logo/favicon/illustration/slogan + curated theme tokens - plan: `documentation/plans/sprint-2/03-tenant-branding.md`.
- **Theme = curated flat JSON** (`{"light":{...},"dark":{...}}`, whitelisted `--foundryx-*` primitive keys, stored as a TRUE DIFF vs Foundryx defaults - default-equal values normalize away). Canonical whitelist+defaults = `app/branding/token_whitelist.py`; frontend mirror = `lib/branding-tokens.ts`, **pinned by a parity test** (`tests/test_branding.py test_frontend_defaults_parity`) - add a primitive → update BOTH + `css/foundryx-tokens.css`. `-transparent` variants are derived (base @ 0.2 alpha), never stored. TWO edit methods over one doc: grouped color pickers AND template download/modify/upload (named 422s on unknown key/bad color).
- **Data**: `tenant_branding` 1:1 (`tokens_json JSON(none_as_null=True)`, asset storage keys+mimes, `version` bumped per mutation → cache-busts `?v=` URLs). One `BrandingService` behind tenant `/branding` (`branding.read/manage`) and operator `/platform/tenants/{id}/branding` (`tenants.manage_branding`); platform tenant = 409 on writes (console keeps stock branding), readable. ONE `raise_branding_http` translator for both routers.
- **Public pre-auth routes** (`/public/branding/{slug}` + `/theme.css` + `/asset/{kind}`): unknown slug = uniform zeroed defaults, NEVER 404 (no tenant enumeration). theme.css emits only overridden vars (`:root`+`.dark`), immutable-cached + ETag. **Asset route serves with `Content-Security-Policy: sandbox` + nosniff** - uploaded SVG executes scripts on direct navigation otherwise (stored XSS; learned in review - full sanitization = BL-067 defense-in-depth).
- **Uploads are sniff-first**: the magic-byte-DETECTED mime is the gate AND the stored type - the declared content-type is extension-derived client input and lies (a JPEG renamed .png). Caps: logo/illustration 2MB (png/jpg/svg/webp), favicon 512KB (+jpeg/webp ok). Old blob deleted best-effort AFTER commit (storage hiccup must not 500 a persisted write).
- **First paint**: root layout derives slug from host → `lib/branding-ssr.ts getRequestBranding` (React `cache`, `revalidate:60`, **2s abort - branding is cosmetic, never block render**) → `generateMetadata` (tab title = tenant name, favicon) + body-first theme.css `<link>` (cascades after foundryx-tokens.css). Whole app = dynamic rendering (accepted cost of per-host theming). `BrandingProvider` re-applies tokens client-side (inline CSS vars on `<html>`) for instant in-session updates; auth layout SSR-seeds `BrandedLayout` so branded tenants never flash the Foundryx logo. **Next 15 streams metadata** (learned via the branding E2E): a client effect's `document.title` write does NOT survive initial load - the (possibly revalidate-stale) SSR `<title>` streams in afterwards and clobbers it; `BrandingProvider` re-asserts via a MutationObserver on `document.head`. Apply the same pattern to any client-side head mutation.
- **White-label copy rule (user mandate)**: tenant-facing UI never says "Foundryx" ("default theme", neutral placeholders); a branded tenant without a logo renders its NAME, never the Foundryx wordmark. Sidebar logo sits on a primary chip (contrast for white/transparent logos); collapsed slot prefers the square favicon - toggle classes (`default-logo`/`small-logo`) live on a bare wrapper, NO display utilities (Tailwind `flex` beats the demo1 collapse CSS).
- **StorageService is core since this plan** (`app/services/storage.py` - `put` keeps the omnichannel URL contract; `save`/`resolve`/`delete` = key-based for core features; omnichannel imports via a re-export shim). `media/` is gitignored.
- **E2E**: `e2e/branding.spec.ts` (3 journeys + report `documentation/plans/sprint-2/03-tenant-branding-test-report.md`). Isolation rules: branding specs must provision a DEDICATED tenant - branding the `default` tenant restyles every concurrent spec's UI mid-run; and never assert "stock branding" against `default` (local manual testing may have branded it) - provision a fresh unbranded tenant instead.
