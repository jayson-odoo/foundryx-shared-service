### Integration core & email (LIVE since sprint-1/09 - the connect-external-services contract)
External-service integrations (SMTP now; storage/LLM/ERP later) plug into CORE primitives - plan: `documentation/plans/sprint-1/09-integration-core-email.md`. **SMTP/email is platform core, never an App Store module** (core auth flows depend on it); business integrations ship as modules that register providers into the same framework.
- **`connections` table** (core `public`): one row per (tenant, provider); `config_json` plain (camelCase keys - displayable) + `credentials_json` Fernet-encrypted via `app/secrets.py` (**`FERNET_KEY`** - required in prod; the omnichannel key migrates onto it in BL-042). Credentials are **write-only** over the API (never echoed; blank on update = keep; partial config PATCH **merges**, never wipes). The PLATFORM tenant's row is the deployment default, env-seeded at bootstrap from `PLATFORM_SMTP_*` (seed refuses loudly if `FERNET_KEY` is unset - two processes can't share an ephemeral key).
- **Provider contract** (`app/integrations/`): registry + `IntegrationProvider` protocol - `fields()` (config schema drives the frontend wizard), `test(config, credentials, target?)` (no target = connection check, with target = targeted test e.g. real test email), `send(...)` for email-type providers. Core registers `smtp` (generic smtplib - covers Gmail/SES/Resend/Mailgun endpoints). `fields()` rows carry two conditional-field keys (full list on the `IntegrationProvider.fields` docstring, `app/integrations/base.py`): `defaultsFrom` (a DEPENDENT default - `sql_provider.py`'s per-dialect port; the field still always renders) and `showWhen` (sprint-5/08, D11 - conditional VISIBILITY; the form hides the field, drops it from `required`, and drops it from the submitted config unless the named sibling field's value is in the list - `modules/autocount/provider.py`'s `auth` select, which hides the vendor credential fields in `none`/open-API mode).
- **Email = outbox, always** (`email_outbox` + `app/services/email_dispatcher.py`): `email_service.send_*(db, to, link, tenant_id)` renders Jinja2 templates (`app/templates/email/`, Foundryx-branded base + text siblings) and enqueues; the dispatcher daemon (lifespan thread, `email_dispatcher_enabled` flag - conftest turns it off) claims under a **lease** (crash-safe reclaim), enforces per-connection `rate_limit_per_minute`, retries 1m/5m/25m, falls back tenant→platform once, prunes sent rows. Resolution skips ERROR connections; **no connection anywhere = dev console-log fallback** (zero-config dev unchanged). Never send product mail outside the outbox (wizard test-send excepted).
- **Tenant UI**: `/settings/integrations` card grid + `components/platform/integration-connect-wizard/` (configure → test connection → done; "send a test email instead" optional; secret fields get eye toggles). Gated by `integrations.read/manage` (core CSV). Retrofit of the omnichannel channel wizard onto this shell = BL-045.
- **ClampedText rule** (user mandate): truncated text must ALWAYS offer the full content - use `components/platform/clamped-text.tsx` (tooltip on real overflow), never a bare `line-clamp-*`/`truncate`.
