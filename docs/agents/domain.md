# Domain documentation

This repository uses a single domain context.

Before exploring or changing a domain area:

- read root `CONTEXT.md` for the shared platform language;
- read relevant decisions under `documentation/adr/` when that directory or matching ADR exists;
- read `PRINCIPLES.md`, root `AGENTS.md`, and the applicable scope-local `CLAUDE.md` before implementation.

Use the glossary's exact terms in issue titles, tests, plans, and code. Surface any contradiction with an existing ADR rather than silently overriding it.
