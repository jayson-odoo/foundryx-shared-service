# Hand test - PR #110 DOC-FEED-INTERVAL (per-feed Document feed schedule)

## URL
crew test copy

## Setup
- Apply the migration first (crew-migration on the PR): `ALTER TABLE app_autocount.ac_doc_feed ADD COLUMN IF NOT EXISTS schedule_config JSON;`
- Sign in as a tenant Admin (holds `autocount.companies.manage`).
- An AutoCount company with an eligible open-API connection, where the Delivery orders feed can be set to Dry run (contract gate open). If none is configured yet, set Delivery orders to that connection + Dry run in step 3 before editing the schedule.

## Steps
1. Sidebar: AutoCount > Companies, open the company.
2. Click the "Document feeds" tab.
3. On the Delivery orders row, open the "..." menu and click "Configure".
4. Look at the two cards under Mode, without changing anything.
5. In "Poll", set Every to 0.
6. Set Every back to 15.
7. In "Deletion sweep", open Mode and choose "Daily at"; set Time to 02:00.
8. Click "Save feed".
9. Open Delivery orders "..." > "Configure" again.
10. Click Cancel. Open Goods receive notes "..." > "Configure".
11. Click Cancel. Go to the company's "Entities" tab, open any entity's "..." > "Configure source", then its "Schedule" tab.
12. Resize the browser to 375 px wide, repeat step 3, then back to 1280 px.

## Expected
- Step 4: a "Poll" card showing Every `60` minutes, and a "Deletion sweep" card with Mode "Every N hours", Every `24` hours (today's cadence, unchanged). If the feed is armed (Dry run / Push), each card shows a "Next ..." badge.
- Step 5: under Poll, red text "At least 1 minute."; the "Save feed" button is disabled.
- Step 6: the error disappears; "Save feed" is enabled.
- Step 8: toast "Document feed updated."; the dialog closes.
- Step 9: Poll shows `15` minutes; Deletion sweep shows Mode "Daily at", Time `02:00` (UTC). With the feed armed, the Poll "Next ..." badge is about 15 minutes after the save time and the Deletion sweep badge is the next 02:00 UTC (10:00 MYT).
- Step 10: Goods receive notes still shows the defaults (Every `60` minutes, Every N hours / `24`): the schedule is per feed.
- Step 11: the Entities Schedule tab looks exactly as before (Incremental, Reconcile, Delete guard cards).
- Step 12: at 375 px the two cards stack vertically with no horizontal scroll; at 1280 px they sit side by side.
