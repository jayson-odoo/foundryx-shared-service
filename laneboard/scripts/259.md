# Hand test - PR #259 META-LEADS-LD (Lead Capture screens: Keys, Delivery, Fields and form maps)

## URL
crew test copy

## Setup
- Crew test copy of branch `crew/meta-leads-ld` (head per crew-handtest). No migration: no new table or column.
- Sign in as `demo@example.com` / `demo1234` (tenant Admin, holds every Lead Capture permission).
- Lead Capture must be installed for the company: Services > Lead Capture > Install if it is not. The sidebar then shows a **Lead Capture** block with Keys, Delivery and Fields.
- No Facebook Page is connected on the copy. The Form maps steps cover the no-Page state only; mapping a real form needs a connected Page (lane L-C) and is covered by the backend and component tests.
- Receivers: use `https://example.com/hooks/lead-capture` (a public placeholder address). Whether the push lands is not part of this test, only the screens.
- Start each part at desktop width (about 1280 px). The last step narrows to phone width.

## Steps
Keys
1. Sidebar: Lead Capture > Keys.
2. Click Create (on the toolbar row, beside Search, Filters, Columns and Export). Leave Name blank and click Create.
3. Click Copy beside the key, then Done.
4. Click Create again, Name = `Test key`, Create, then Done.
5. On the `Test key` row open the row menu (the three-dot button) > Revoke. Click Cancel on the countdown toast before it ends.
6. Again Revoke on `Test key`, and let the countdown end.
7. Hover a long Name or Key cell (narrow the window if nothing is cut).
8. Sort by Created, open Filters > Status = Revoked, then reload the page.
9. Right-click an Active key row (on a phone: long-press; Android only, see Expected).

Delivery
10. Sidebar: Lead Capture > Delivery.
11. Click Push to my system (if not already chosen), then Create. URL = `http://localhost:9000/x`, Events = New lead, click Add.
12. Change URL to `https://example.com/hooks/lead-capture`, click Add.
13. Click Copy beside the signing secret, then Done.
14. On the new receiver row open the row menu > Send test push.
15. Row menu > Remove, then Cancel on the countdown toast.
16. Click Pull only.
17. In the "Switch to pull only?" dialog click Cancel, then click Pull only again and confirm.
18. Click Copy beside the leads address.
19. Reload the page.
20. Add receivers again (steps 11-13, each with its own https URL, e.g. `https://hooks1.example.com/lead-capture`) until the list has 5, then try one more. Right-click any receiver row.

Fields
21. Sidebar: Lead Capture > Fields. Read the Lead fields card.
22. Click Add field. Key = `budget range` (with a space), Label = `Budget`, Type = Text. Click Save fields.
23. Change Key to `budget_range`, click Save fields.
24. On the new line open its line menu > Move up, then Save fields.
25. Click Use defaults, then Cancel on the countdown toast.
26. Click Use defaults again and let the countdown end.
27. Read the Form maps list, then click Add form.
27a. If the copy has a (dev) Page with an "All forms" row in Form maps: click that row.
28. Narrow the window to about 375 px and walk Keys, Delivery and Fields again (open one dialog on each page).

## Expected
- Step 1: list columns Name, Key (masked `fxl_live_****xxxx`), Created, Last used, Status. Toolbar on ONE row: Search, Filters, Columns, Export, Create. No sideways scrollbar at 1280.
- Step 2: the popup switches to "Key created" and shows the full key once. The new row is named "Lead Capture key".
- Step 3: Copy shows a tick (works on plain http too). After Done the full key is never shown again; the row shows only the masked key.
- Step 5: a toast with a countdown and Cancel. After Cancel the key stays Active.
- Step 6: the row stays listed with Status Revoked.
- Step 7: the cut text ends in "..." and the hover shows the full text, starting at the cell's left edge.
- Step 8: dates read dd/mm/yyyy, h:mm am/pm. After reload the sort and filter are kept (they ride the address bar).
- Step 9: the same menu as the three-dot button (Revoke) opens at the pointer. Long-press opens it on Android; iPhone/iPad Safari does not fire it (shared list, #253).
- Step 10: with no receivers the page opens on Pull only; with receivers, on Push to my system.
- Step 11: the popup stays open with red text under URL: "The URL cannot target localhost." (an `http://` public address reads "The URL must use https://."). Never "Callback URL". Nothing is added.
- Step 12: the popup switches to "Receiver added" and shows the signing secret once.
- Step 13: the list shows the receiver: URL, Events "New lead", Added (dd/mm/yyyy), Last delivered "-".
- Step 14: toast "Test push sent."
- Step 15: countdown toast with Cancel; after Cancel the receiver stays.
- Step 16: dialog "Switch to pull only?" with "1 receiver will be removed. New leads will no longer be pushed to it."
- Step 17: Cancel keeps Push and the receiver. Confirm: toast "Leads are now pull only.", the leads address panel shows, the receiver is gone.
- Step 18: Copy shows a tick.
- Step 19: the page opens on Pull only.
- Step 20: the sixth Add is refused with red text under URL: "At most 5 receivers."; the list shows 5. Right-click opens Send test push and Remove at the pointer; a Remove from there (after its countdown) also updates the page (Pull only once none are left).
- Step 21: four default lines: Name, Phone, Email, Lead notes. Save fields is disabled until something changes; "Use defaults" is not shown while the list is the default.
- Step 22: red text next to the key: "Use letters, digits or _, starting with a letter." Nothing saved.
- Step 23: toast "Lead fields saved."; "Use defaults" now shows.
- Step 24: the line moves up one place and stays there after the save.
- Step 25: countdown toast "Setting default fields" with Cancel; after Cancel the list still has `budget_range`.
- Step 26: the list goes back to the four defaults; "Use defaults" hides again.
- Step 27: Form maps shows an empty list. Add form shows "No Facebook Page is connected yet." and Next stays disabled. Form maps' Create is the only filled (orange) button on the page.
- Step 27a: "Map fields: All forms" lists the questions by name (e.g. "Full name", "Email", "Phone number"), each once; a stored line no form asks any more reads in plain words ("Q old budget"). No raw key such as `full_name` anywhere.
- Step 28: no sideways scrolling on any page; Lead fields lines stack one under the other; dialogs fit the screen; toolbars wrap instead of overflowing.
