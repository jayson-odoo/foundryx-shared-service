# Hand test - PR #259 META-LEADS-LD (Lead Capture screens: Keys, Delivery, Fields and form maps)

## URL
crew test copy

## Setup
- Crew test copy of branch `crew/meta-leads-ld` (head per crew-handtest). No migration: no new table or column.
- Sign in as `demo@example.com` / `demo1234` (tenant Admin, holds every Lead Capture permission).
- Lead Capture must be installed for the company: Services > Lead Capture > Install if it is not. The sidebar then shows a **Lead Capture** block with Keys, Delivery and Fields.
- Meta is not configured on the copy. If a dev Page is connected (Form maps lists rows), step 27a applies. With no Page, step 27 covers the empty state.
- Receivers: use `https://example.com/hooks/lead-capture` style public placeholder addresses. Whether the push lands is not part of this test, only the screens. In a crew pass, repoint the receiver to a local address before step 14 so nothing leaves the machine (the copy then refuses the send; the toast still shows).
- Start each part at desktop width (about 1280 px). The last step narrows to phone width.

## Steps
Keys
1. Sidebar: Lead Capture > Keys.
2. Click Create (on the toolbar row with Search, Filters, Export and Columns). With Name blank, look at the popup's Create button; then type Name = `CRM sync` and click Create.
3. Click Copy beside the key, then Done.
4. Click Create again, Name = `Test key`, Create, then Done.
5. On the `Test key` row open the row menu (the three-dot button) > Revoke. Click Cancel on the countdown toast before it ends.
6. Again Revoke on `Test key`, and let the countdown end.
7. Hover a long Name or Key cell (narrow the window if nothing is cut).
8. Sort by Created, open Filters > Status = Revoked, then reload the page.
9. Right-click an Active key row (on a phone: long-press; Android only, see Expected).

Delivery
10. Sidebar: Lead Capture > Delivery.
11. Click Push to my system (if not already chosen), then Create. URL = `https://localhost:9000/x`, Events = New lead, click Add. Then try `http://hooks.example.com/x` and `https://exa mple.com/x`.
12. Change URL to `https://example.com/hooks/lead-capture`, click Add.
13. Click Copy beside the signing secret, then Done.
14. On the new receiver row open the row menu > Send test push.
15. Row menu > Remove, then Cancel on the countdown toast.
16. Click Pull only.
17. In the "Switch to pull only?" dialog click Cancel, then click Pull only again and confirm.
18. Click Copy beside the leads address.
19. Reload the page.
20. Type `hooks` in Search, then clear it. Add receivers again (steps 12-13, each with its own https URL, e.g. `https://hooks1.example.com/lead-capture`) until the list has 5, then try one more. Right-click any receiver row > Remove, let the countdown end; repeat until none are left.
20a. Add one receiver. In a second tab remove it (row menu > Remove, let the countdown end). Back in the first tab (not reloaded), right-click its row > Remove, then > Send test push.
20b. With receivers listed: type `hooks` in Search and reload the page; clear the search; sort URL descending (URL header > Desc). Click Pull only and confirm, then click Push to my system.

20c. On Keys (or Delivery with receivers): type one letter in Search and at once click Lead Capture > Fields in the sidebar. Repeat 3 times.
20d. On Keys: type `crm` in Search and sort by Name. Click Lead Capture > Keys in the sidebar (the page you are on), then reload.

Fields
21. Sidebar: Lead Capture > Fields. Read the Lead fields card.
22. Click Add field. Key = `budget range` (with a space), Label = `Budget`, Type = Text. Click Save fields.
23. Change Key to `budget_range`, click Save fields.
24. On the new line open its line menu > Move up, then Save fields.
25. Click Use defaults, then Cancel on the countdown toast.
26. Click Use defaults again and let the countdown end.
27. Read the Form maps list, then click Add form.
27a. If Form maps has an "All forms" row: click that row.
28. Narrow the window to about 375 px and walk Keys, Delivery and Fields again (open one dialog on each page).
