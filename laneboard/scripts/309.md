## Setup
Done by crew before handing over:
1. Copy on the PR head, `python -m scripts.bootstrap_db` run.
2. Ideation installed on the demo tenant (Services), with one product and one feedback item that is not a test item.
3. A stub CRM on the copy machine (no real CRM, no WhatsApp): it answers
   `POST /api/v1/external/ideation/contacts/lookup` with 200 `{contactId, name, phone}`, but with 404 for any number
   ending in `9999`. It answers `POST /api/v1/external/ideation/phone/send-code` with 202 and writes the `code` it
   received to a local file. Crew reads the code from that file for the tester.
4. One active `consumer` connection on the demo tenant: `config.baseUrl` = the stub, `config.productId` = the item's
   product, any test API key.
5. For section C only: the tenant's public-link base set to a CRM template (e.g. `https://<crm host>/portal/ideas/{token}`).

## Steps
### A. Phone step (desktop, 1280 wide)
1. Sign in to the Shared Service as the demo Admin and open the feedback item.
2. Open "..." on the item, choose Share link, copy the link. Open the SS share page for that token in a new tab.
3. Click Follow.
4. Look at the phone row.
5. Type `0123` and click Continue.
6. Clear the field, type `012-345 9999`, click Continue.
7. Click the flag button, type `singa` in the search box, press Escape.
8. Clear the field, type `012-345 0002`, click Continue.
### B. Code step (same dialog)
1. Read the text above the code field and the button under it.
2. Type `000000` in Verification code (or `111111` if the stub's code is `000000`).
3. Type the code from the stub's file.
### C. Share link host (CRM tenant)
1. With setup 5 done, open the item again, open "..." and choose Share link.
### D. Phone width
1. Repeat A3 to B3 at 375 px wide (phone or browser device mode).
