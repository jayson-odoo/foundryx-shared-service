# Hand test - PR #318 FEEDBACK-COMMENT-PHONE-LIKE-PORTAL (comment dialog phone + code steps same as the CRM sign-in)

Fake numbers only. The stub CRM writes the code to a file; nothing is sent over WhatsApp.

## URL
crew test copy

## Setup
Same as PR #309 (`laneboard/scripts/309.md` Setup 1-4): copy on this PR head, `python -m scripts.bootstrap_db`, Ideation installed with one product and one real (not test) feedback item, the stub CRM (404 for numbers ending `9999`, send-code writes the code to a file), one active `consumer` connection for that product. Open the CRM portal sign-in (`/signin`, phone mode) in a second window for side by side.

## Steps
1. Open the item's share link (item "..." > Share link > copy), open it in a new tab, click Comment.
2. Look at the phone row and the Continue button before typing.
3. Type `0123`, press Enter.
4. Click Continue.
5. Clear the field, type `012-345 9999`, click Continue.
6. Clear the field, type `012-345 0002`, click Continue.
7. Type `00000` then one more wrong digit (a code that is not the stub's code).
8. Repeat step 7 four more times.
9. Click Change number.
10. Click Continue, type the stub's newest code.
11. Repeat steps 1 to 10 at 375 px wide.
12. Open the webchat panel with "Ask phone" on: look at the Phone field, type `0123`, type a message, click Send; then type `012-345 0002` and Send.

## Expected
- 2: the field is labelled `Phone number`, flag button reads "Country: Malaysia (+60)", `+60` next to the field, placeholder `12-345 6789`, the field does not have the cursor, Continue is greyed out.
- 3: nothing happens (Enter does not send).
- 4: under the field in red: `Enter a complete phone number.`; nothing reaches the stub.
- 5: a red box: `This number isn't registered with <product>. Ask your <product> contact to add you.`
- 6: code step: `We'll send a code to your WhatsApp +60 12 345 0002`, `Change number` link, `Verification code` field (placeholder `6-digit code`, has the cursor), `Resend in 60s` counting down to `Resend code`. No Verify button.
- 7: at the 6th digit, `Checking the code for +60 12 345 0002` with a spinner, the field locked; then a red box `That code is not right. 4 tries left.`, the field empty with the cursor.
- 8: `3 tries left.`, `2 tries left.`, `1 try left.`, then `That code is not right.`
- 9: back to the phone step with `12-345 0002` still in the field.
- 10: a fresh code step with `Resend in 60s`; after the 6th digit of the right code the visitor lands on their own feedback board, on this item.
- 11: same texts; nothing runs off the screen; the country list scrolls inside its box.
- 12: the Phone field looks like step 2; `0123` + Send shows `Enter a complete phone number.` and keeps the message; `012-345 0002` + Send sends it.
- Side by side with the CRM sign-in: same field, same code step. Differences on purpose: the status line reads "Checking the code for ..." (CRM: "Signing you in as ..."); letters cannot be typed into the code field.
