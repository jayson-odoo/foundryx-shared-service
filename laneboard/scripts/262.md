# Hand test - PR #262 META-LEADS-LC (Lead Capture: connect a source from a product)

Two modes. Mode A (Simulator) works now, from the phone. Mode B (Real Facebook) needs the Meta setup in section B0
and runs in a browser on the Mac (Meta accepts a plain-http redirect only for `localhost`).

The "product" is a small TEST page on the copy (`/public/lead-capture/test-consumer`). It stands in for EcoHub's
"Connect a source" button: its server holds a Lead Capture key, opens the connect wizard and lists the leads the
key receives. It exists only on test copies (switched on by two server env values; production never sets them).

## URL
crew test copy

- Phone (Mode A): `http://100.127.79.93:3109/public/lead-capture/test-consumer`
- Mac (Mode B): `http://localhost:3109/public/lead-capture/test-consumer`
- Shared Service screens: `http://100.127.79.93:3109` (phone) or `http://localhost:3109` (Mac), sidebar Lead Capture.
  Sign in with the demo tenant Admin login listed in the repo's `CLAUDE.md`, "Commands > Backend" ("Demo logins").
  The test page itself needs no sign-in.

## Setup
Done by crew before handing over:
1. Copy on the PR head, `python -m scripts.bootstrap_db` run (Lead Capture migration 0005).
2. Lead Capture installed on the demo tenant (Services).
3. Backend `.env`: `ENVIRONMENT=development` (lets the key list a plain-http tailnet origin);
   `CORS_ORIGINS` includes `http://100.127.79.93:3109` and `http://localhost:3109`.
4. Frontend built with `NEXT_PUBLIC_BACKEND_API_URL` = the copy backend's TAILNET address (reachable from the phone,
   not `localhost`), so the wizard works on the phone.
5. A Lead Capture key "Test CRM" made by the demo Admin (`POST /lead-capture/keys`) with
   `allowedOrigins: ["http://100.127.79.93:3109", "http://localhost:3109"]`.
6. Frontend server env (runtime, no rebuild): `LEAD_CAPTURE_TEST_CONSUMER=on` and
   `LEAD_CAPTURE_TEST_CONSUMER_KEY=<that key>`. Restart the copy frontend.
7. Mode A: backend `.env` has NO `META_APP_ID` (simulated Facebook). Mode B: section B0 below.

## Steps
### A. Simulator (phone)
1. Open the phone URL above.
2. Tap "Connect a source". A new tab/popup opens the wizard.
3. Tap "Facebook".
4. Tap "Continue with Facebook".
5. In the Page list pick "Sample Home Page", tap "Connect Page".
6. Tap "Only the forms I tick" (leave nothing ticked) and read the button.
7. Tap "All forms, including new ones", tap "Save forms".
8. Tap "Save fields".
9. Tap "Send test lead".
10. When the steps fold, tap the "Which lead forms?" line once, then tap "Finish setup".
11. Tap "Done".
12. Back on Test CRM, wait 10 seconds (or tap "Refresh leads").
13. Tap "Connect a source" again, go through steps 3-4, pick "Sample Home Page" again and tap "Connect Page".
14. Sign in to Shared Service, open Lead Capture > Sources, tap the "Sample Home Page" row, then tap the test lead.

### B0. Real Facebook - what the owner adds in the Meta app (once)
Full detail: PR #262 comment "META CONFIG STEPS".
1. Facebook Login for Business > Configurations > Create configuration: variation General, token type User access
   token, expiry 60 days.
2. Tick exactly `pages_show_list`, `pages_manage_metadata`, `pages_read_engagement`, `leads_retrieval`,
   `pages_manage_ads`. Assets: Pages (the Foundryx Page).
3. Facebook Login for Business > Settings > Valid OAuth Redirect URIs: add `http://localhost:3109/wa-callback`.
   "Client OAuth login" and "Web OAuth login" ON.
4. Send crew the new configuration's Configuration ID.
Then crew: backend `.env` gets `META_APP_ID`, `META_APP_SECRET` (same app) and `LEAD_CAPTURE_LOGIN_CONFIG_ID=<id>`,
restarts the backend. For the test lead to arrive, Meta must reach the copy: crew points the app's `page`
webhook (field `leadgen`) at a public HTTPS tunnel to the copy backend `/omnichannel/webhooks/lead`
(verify token = `META_WEBHOOK_VERIFY_TOKEN`), and restores the app's webhook list after the test
(`documentation/plans/meta-leads/META-LIVE-RUN-plan.md` steps 2 and Cleanup).

### B. Real Facebook (Mac browser)
1. Open the Mac URL above.
2. Click "Connect a source", then "Facebook", then "Continue with Facebook".
3. In Meta's window, untick `leads_retrieval` (Leads) and finish.
4. Click "Try again" and finish Meta's window with every permission ticked.
5. Pick the Foundryx Page (it is picked for you if it is the only Page shared), click "Connect Page".
6. Keep "All forms, including new ones", click "Save forms".
7. Check the field picks, click "Save fields".
8. Pick the test form, click "Send test lead".
9. When the Test step folds, click "Finish setup", then "Done".
10. On Test CRM, wait 10 seconds.
