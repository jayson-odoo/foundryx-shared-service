# Hand test - PR #262 META-LEADS-LC (Lead Capture: connect a source from a product)

Two modes. Mode A (Simulator) works now, from the phone. Mode B (Real Facebook) uses the owner's configuration 1195301273170561 (section B0)
and runs in a browser on the Mac (Meta accepts a plain-http redirect only for `localhost`).

The "product" is a small TEST page on the copy (`/public/lead-capture/test-consumer`). It stands in for EcoHub's
"Connect a source" button: its server holds a Lead Capture key, opens the connect wizard and lists the leads the
key receives. It exists only on test copies (switched on by two server env values; production never sets them).

## Steps
### A. Simulator (phone)
1. On the phone open `http://100.127.79.93:3109/public/lead-capture/test-consumer`.
2. Tap "Connect a source". A new tab/popup opens the wizard.
3. Tap "Facebook".
4. Tap "Continue with Facebook".
5. In the Page list pick "Sample Home Page", tap "Connect Page".
6. Tap "Only the forms I tick" (leave nothing ticked) and read the button.
7. Tap "All forms, including new ones", tap "Save forms".
8. Tap "Save fields".
9. Tap "Send test lead".
10. When the steps fold, tap the "Which lead forms?" line once, then tap "Finish setup".
11. Tap "Done".
12. Back on Test CRM, wait 10 seconds, then tap "Refresh leads".
13. Tap "Connect a source" again, go through steps 3-4, pick "Sample Home Page" again and tap "Connect Page".
14. Open `http://100.127.79.93:3109/` and sign in as the `default` tenant demo admin (account listed in the SS
    repo `CLAUDE.md` line 26, "Demo logins"). At phone width tap "Open navigation" (top left), then Lead Capture >
    Sources. Tap the "Sample Home Page" row, then tap the test lead.
15. Back on Lead Capture > Leads: tap the "Received" header (sorts), open its menu and tap "Clear sort"; type
    "lead.test" in Search; reload the page.

### B0. Real Facebook - Meta app and copy settings
Owner side (done 18 Nov): Facebook Login for Business configuration **1195301273170561** (General, user access
token, 60 days, the 5 Page/lead permissions, Pages only) and `http://localhost:3109/wa-callback` under Valid OAuth
Redirect URIs.

Crew sets on the copy BACKEND `.env` only (never in git, a PR comment or a log), then restarts the backend:
- `LEAD_CAPTURE_LOGIN_CONFIG_ID=1195301273170561`
- `META_APP_ID` = the App ID of the Meta app that owns that configuration (Meta app dashboard > App settings >
  Basic > App ID). It is the same app production uses: GitHub secret `META_APP_ID`, written into the production
  `.env` by `.github/workflows/deploy.yml:429`.
- `META_APP_SECRET` = that app's App secret (same dashboard page, "Show"; or the production server `.env` /
  GitHub secret `META_APP_SECRET`, `deploy.yml:430`). Copy it straight into the copy's `.env`; never print it.
- optional `META_GRAPH_VERSION=v25.0`.
No frontend rebuild: the wizard reads the App ID and configuration id from the backend at run time. To go back to
Mode A, remove `META_APP_ID` and restart the backend.

For the test lead to arrive, Meta must reach the copy: crew points the app's `page` webhook (field `leadgen`) at a
public HTTPS tunnel to the copy backend `/omnichannel/webhooks/lead` (verify token = `META_WEBHOOK_VERIFY_TOKEN`)
and restores the app's webhook list after the test (`documentation/plans/meta-leads/META-LIVE-RUN-plan.md` step 2
and Cleanup).

### B. Real Facebook (Mac browser)
1. On the Mac open `http://localhost:3109/public/lead-capture/test-consumer`.
2. Click "Connect a source", then "Facebook", then "Continue with Facebook".
3. In Meta's window, if it lets you switch a permission off, switch off the leads permission and finish (skip
   steps 3-4 if the window offers no switches).
4. Click "Try again" and finish Meta's window with every permission ticked.
5. Pick the Foundryx Page (it is picked for you if it is the only Page shared), click "Connect Page".
6. Keep "All forms, including new ones", click "Save forms".
7. Check the field picks, click "Save fields".
8. Pick the test form, click "Send test lead".
9. When the Test step folds, click "Finish setup", then "Done".
10. On Test CRM, wait 10 seconds.
