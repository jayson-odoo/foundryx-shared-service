Ideation — Capture Quality + Embed Parity

Three defects surfaced when eyeballing the live embed on fe-sorento.foundryx.my. This plan fixes capture identity + raw notes, and collapses the duplicated iframe UI onto the operator grid. Decisions below are already grilled & locked — annotate anything you want changed.

What's broken today

1 · Submitter "Unknown"

Every captured idea shows Unknown as submitter. The sender's name is never carried into the idea.

2 · Raw notes = last line

Raw notes store only the final message — usually "okay i confirm". The actual conversation is lost.

3 · Duplicated iframe UI

The iframe renders a bespoke simple list/detail, separate from the operator grid → two UIs to maintain.

Where the fixes land — capture pipeline

No new WhatsApp channel. Identity + transcript ride the existing Respond.io → n8n → turn flow. Shared-service stays a no-LLM sink (D20).

The three workstreams

WS-A Submitter name small · sorento-only
  • Sorento turn service: extend _get_contact_row SELECT to include name/first_name/last_name; send submitter_name (DB name → n8n fallback → None).
  • Shared-service create_idea: accept the string, store idea.submitter_name directly (not the Contact copy — G4).
  • Serializer already prefers idea.submitter_name (ideas.py:61).
AC-CAP-1..4
WS-B Cumulative raw notes small · cross-repo
  • Sorento accumulates each turn in session_vars.ideation (length-capped); sends full raw_transcript.
  • Shared-service stores raw_transcript → raw_text; stops overwriting with the last message (intake.py:288). Falls back to message_text when absent.
  • message_text stays current-turn → extraction + trigram dedup unchanged.
AC-CAP-5..8
WS-C Embed = operator grid parity big · security
C1 · One component, two modes (FE)

Refactor the operator list/grid + detail to take mode: operator | embed. Delete embed-ideas-board.tsx / embed-idea-detail.tsx; the iframe mounts the shared component chrome-less.

C2 · Embed-authed operator writes (BE)

Dedicated /embed/* write routes reusing the operator services, each asserting principal.tenant_id AND principal.product_id. Prereq: put connection.product_id in the token + pass to list/board(product_id=).

C3 · Session longevity

Keep the 5-min token; iframe silently re-mints via the host handshake on 401 (G5).

Risks / watch
